Atividade intermediária de Consumo de API — Programação Front-End.

🎯 O que é

Uma aplicação web que consome a API pública da Open Library para permitir a busca de livros por título, autor, assunto ou ISBN. Os resultados são exibidos em cards com capa, ano e número de edições.

Todo o código foi escrito em JavaScript puro, sem frameworks ou bibliotecas para requisições — apenas fetch, async/await e manipulação direta do DOM.

✅ Requisitos atendidos

RF01

Entrada de dados

Campo de busca com filtro por campo e ordenação.

RF02

Consulta à API

Requisição fetch com async/await para a Open Library.

RF03

Apresentação

Exibe 3+ informações: título, autor, ano, edições, capa.

RF04

Resposta inválida

Mensagem quando nenhum livro é encontrado.

RF05

Erro de comunicação

Tratamento de falhas de rede com mensagem clara.

RF06

Atualização dinâmica

Todo o conteúdo renderizado via JavaScript, sem reload.
